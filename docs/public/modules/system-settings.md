# 系统设置

系统设置用于配置模型供应商、API Key、知识库连接、数据库相关偏好和基础运行选项。第一次使用时，系统设置是必须完成的入口。

![模型与任务路由界面截图](../../../images/模型配置.png)

## 优先配置什么

建议按这个顺序配置：

1. 模型供应商。
2. API Key。
3. Base URL。
4. 默认模型。
5. 连接测试。
6. 可选知识库设置。
7. 可选任务和界面偏好。

先确认模型可用，再进入新手上路。

## GitHub Copilot 订阅

已有 Copilot 订阅时，可从“设置 → 授权中心”登录 GitHub，在浏览器完成设备码授权。
首次登录会创建一个 Copilot 连接并读取可用文本模型，不覆盖已有默认模型。

需要多套模型配置时，在“模型与厂商”添加自定义厂商，将连接来源选择为“GitHub Copilot 订阅账户”。
每套连接可分别选择默认模型和请求限制，无需填写 API Key 或 API 地址。
目录未准备好时，可在授权中心或厂商详情点击“刷新模型”。
首次创作需要准备任务路由时，可在快捷配置中选择这个订阅连接，直接检测并完成配置，无需补填 API 地址。

每个部署实例只保存一个账户，多个连接共享该账户。退出登录保留厂商配置和小说；
重新登录同一 GitHub 身份后可继续使用原绑定。另一身份需要先退出并确认关联范围。
创作任务若因授权问题中断，完成授权后回到任务来源工作台处理，不在运行记录中恢复。

订阅只接入可支持的文本模型，不用于图片或知识库向量。可用模型、调用限额和组织授权以 GitHub 为准，
接口变化可能影响兼容性；连接测试和生成会消耗订阅额度。

只在可信部署中授权。远程 Web 部署应启用应用访问令牌保护并使用 HTTPS；
GitHub 登录不替代应用访问保护，同一部署的访问者共用账户。
Web 部署通过 `AI_NOVEL_CREDENTIALS_DIR` 指定持久化私有凭据目录；
桌面由应用管理该目录。迁移已有授权需要数据库和对应凭据密钥，普通日志包不包含密钥。

## API Key 和供应商

填写 API Key 时注意：

- 不要多复制空格。
- 确认 Key 对应的供应商和 Base URL。
- 确认账户额度和模型权限。
- 如果供应商兼容 OpenAI 接口，按兼容接口填写。

连接失败时，先用供应商控制台或简单请求确认 Key 是否有效，再回到应用测试。

首次快捷配置中，OpenAI 兼容接口使用“添加第三方厂商”。第三方厂商会独立保存 API Key、Base URL 和模型，不会覆盖 DeepSeek、OpenAI 等内置厂商。需要同时保留多套连接时，分别创建厂商并在模型路由中选择。

## Base URL 和模型名称

Base URL 需要和供应商文档一致。常见问题包括：

- 多写或少写路径。
- 使用了网页地址而不是 API 地址。
- 模型名称和供应商实际名称不一致。
- 代理或网络限制导致请求无法到达。

模型名称建议从供应商文档复制，不要自行猜测。

## Qdrant 设置

Qdrant 用于知识库向量检索。它不是开书和生成第一章的硬性前置条件，但会影响资料召回、拆书沉淀和长期一致性。

配置时确认：

- Qdrant 服务可访问。
- 地址和端口正确。
- 集合或命名策略符合应用配置。
- 索引任务能够完成。

知识库不命中时，不要只改提示词；先确认 Qdrant 连接和索引状态。

## 自动导演问题处理

“自动导演”设置页用于选择全局问题处理默认值。每本书也可以保存自己的覆盖规则。

- 优先完成整本书：局部问题处理一次后保留可用正文、记录质量债并继续。
- 质量优先：局部问题处理一次后仍未解决，停在安全章节边界等待确认。
- 逐项规则：可以选择自动重试、提醒后继续、暂停处理或结束任务。
- 安全保护：保存失败、数据完整性风险和受保护内容仍会优先暂停或结束任务。

本书覆盖适合不同项目采用不同质量策略；需要恢复统一设置时，在小说中选择“恢复继承全局”。

## 自动导演单章预算

在“设置 → 自动导演”调整单章 AI 用量上限，默认 **100,000 Tokens**，可设置 **16,001—10,000,000** 的整数。设置保存后用于新任务，重启软件仍会保留。

这是写作、审校、修文及资料同步等调用的累计用量保护，与模型的单次最大输出不同。按未命中输入与输出累计统计，Tokens 不等于实际费用。

在本书导演台开始创作时，可以展开“更多创作设置”单独填写本次任务的上限；留空沿用全局设置。任务开始后保留当时的额度，恢复时继续使用。

达到上限或剩余额度不足以覆盖下一步预留时，创作暂停并保留进度。可提高本章预算后继续，也可勾选“同时应用于本任务后续章节”。不勾选时只调整本章；全局默认设置不随追加额度改变。选择“保持暂停”可稍后处理。

## SQLite 和本地数据

桌面版会保存本地数据库和配置。请把它当作重要数据处理：

- 不要随意删除数据库文件。
- 重要小说定期导出或备份。
- 迁移、重置或清理前先确认备份。
- 排查问题时保留日志和数据副本。

任何可能删除数据的操作都应先备份。

## 设置后的验证

完成设置后，建议执行一个最短验证：

1. 测试模型连接。
2. 创建测试小说。
3. 让自动导演生成方向候选。
4. 生成第一章。
5. 查看运行记录状态。

这条路径能同时验证模型、数据库、任务队列和主链入口。
