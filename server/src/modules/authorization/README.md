# 授权与订阅连接

## 所有权

- `domain/` 定义单账户、代次、状态与对外错误。
- `application/` 编排设备登录、有效凭据和 provider 绑定，依赖注入的存储与上游端口。
- `infrastructure/` 实现 Prisma 存储与 GitHub/Copilot HTTP 合同。
- `http/` 只映射管理请求，不提供模型推理路由。
- `composition.ts` 创建惰性单实例并连接平台代理；外部模块经 `index.ts` 使用 facade。

平台 `subscription-proxy` 只认识注入的 SubscriptionPort，不反向导入本模块。
LLM 工厂拥有 SDK 构造和业务装饰，不能接管账户状态或保存 token 副本。
普通 API Key 的鉴权方式与订阅连接来源是独立字段。

## 生命周期

GitHub OAuth 凭据加密保存，短期 Copilot token 只缓存于内存。代次在退出/重新授权时递增，
每次物理发送检查账户与 provider 绑定。退出取消 pending 会话、共享刷新、排队项和在途流，
但不删除账户槽位、厂商配置或创作数据。

首次 provider 创建和首次配置标记处于同一事务；模型目录单独刷新，失败不能回滚有效授权。
状态读取不探测上游；已授权不等于已就绪，目录和默认模型必须同样可用。
相同身份重连不覆盖用户模型/隐藏项或当前选择；另一身份需要显式确认受影响绑定。
退出保留身份以保护共享厂商的归属。普通重连与换号是独立命令意图，换号需在退出后确认，
`replaceAccount` 在设备会话创建时固定；并发创建与 pending 会话复用都必须校验模式一致。
UI 显式提供“登录原账户”和“切换 GitHub 账户”，不能以隐藏复选状态或身份不匹配代替换号确认。

验证边界见已批准 spec。真实 OAuth 与订阅推理必须和模拟上游的 SDK/数据库测试分别报告。
